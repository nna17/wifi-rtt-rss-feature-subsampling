# Datasets

The datasets are public but are not redistributed in this repository. Download them from their original sources and place the files in this folder with exactly these names.

## Dataset I: hybrid RTT–RSS benchmark (Building, Office, Apartment)

Feng, Nguyen, and Luo, "Robust Indoor Positioning with Hybrid WiFi RTT-RSS Signals," *Sensors*, 26(1):284, 2026. Data: <https://doi.org/10.5281/zenodo.11558192> (also on GitHub: <https://github.com/Fx386483710/WiFi-RTT-RSS-dataset>, in its `dataset/` folder)

```
database_building_train.csv
database_building_test.csv
database_office_train.csv
database_office_test.csv
database_apartment_train.csv
database_apartment_test.csv
Floor+office+apartment_AP_coords.txt   (used only by scripts/screening/new_ideas.py)
```

## Dataset II: EETAC Auditorium (Google Pixel 3a, two acquisition days)

Collected by Enrica Zola and Israel Martín-Escalona (Universitat Politècnica de Catalunya). Data: <https://github.com/imartin-UPC/RTT-Data-Collection>

```
EETAC Auditorium-C3-0-google-Pixel 3a-RSS-day 1.csv
EETAC Auditorium-C3-0-google-Pixel 3a-RTT-day 1.csv
EETAC Auditorium-C3-0-google-Pixel 3a-RSS-day 2.csv
EETAC Auditorium-C3-0-google-Pixel 3a-RTT-day 2.csv
```

`README_EETAC_original.md` is the README distributed with the EETAC files.
